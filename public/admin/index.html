Integrasi Database: Google Sheets

Simpan seluruh konten frontend, profil kamar, dan reservasi di Google Spreadsheet Anda tanpa biaya database bulanan.

Panduan Pasang Script Google Apps Script:

Kode script lengkap telah disediakan di file google-apps-script/Code.gs. Buka spreadsheet baru di Google Drive, klik Extensions > Apps Script, tempelkan kode tersebut, jalankan fungsi setupDatabase, lalu deploy sebagai Web App dengan izin akses "Anyone".
